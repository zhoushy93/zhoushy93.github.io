# Personal Academic Website

把此目录上传到 `YOUR_GITHUB_USERNAME.github.io` 即可作为 GitHub Pages 个人主页。

## 只需修改
- `_config.yml`：网站标题和 URL
- `index.md`：姓名、学校、简介、联系方式、News
- `_data/publications.yml`：论文信息
- `assets/img/avatar.jpg`：头像
- `assets/img/paper*.svg`：替换为论文缩略图
- `files/cv.pdf`：替换为自己的 CV

## GitHub Pages
1. 创建 `YOUR_GITHUB_USERNAME.github.io` 仓库。
2. 把此目录所有文件上传到仓库根目录。
3. Settings → Pages → Deploy from a branch → `main` / root。
4. 等待 GitHub Pages 构建完成。
